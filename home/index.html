About

I'm an IT Director, network administrator, and security engineer. I run infrastructure by day and a homelab by night — where I build the kind of tools that usually live behind enterprise licenses.

Everything you see here is live and running on a Debian 13 server in my basement. Nginx out front, Node.js APIs, MariaDB in the back, all behind a hardened UFW firewall with Fail2Ban watching the logs. No managed cloud. No SaaS front-ends. Just the full stack, end to end.
